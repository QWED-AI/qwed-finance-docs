## Overview

**QWED Finance** provides zero-hallucination, deterministic security and verification guards for AI financial agents, automated banking pipelines, and financial LLM applications.

By combining LLM translation with formal solvers (**SymPy**, **Z3**, **mpmath**) and exact `Decimal` arithmetic, QWED Finance ensures that financial calculations, compliance rules, portfolio risks, and transaction logic are provably correct before shipping to users or executing trades.

> **The Financial Guarantee**: LLM text generation is probabilistic; financial accounting is exact. QWED Finance bridges this gap by validating LLM outputs against symbolic solvers, producing cryptographic attestations and zero-hallucination guarantees.
