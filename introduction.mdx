## Overview

**QWED Finance** provides zero-hallucination, deterministic security and verification guards for AI financial agents, automated banking pipelines, and financial LLM applications.

By combining LLM translation with formal solvers (**SymPy**, **Z3**, **mpmath**) and exact `Decimal` arithmetic, QWED Finance ensures that financial calculations, compliance rules, portfolio risks, and transaction logic are provably correct before shipping to users or executing trades.

> **The Financial Guarantee**: LLM text generation is probabilistic; financial accounting is exact. QWED Finance bridges this gap by validating LLM outputs against symbolic solvers, producing cryptographic attestations and zero-hallucination guarantees.

## What's New in QWED Finance v6.0.0

<AccordionGroup>
  <Accordion title="Unified DiagnosticResult Schema" icon="shield-check" defaultOpen>
    All financial verifiers return the 3-layer `DiagnosticResult` (`status` / `agent_message` / `developer_fields` / `proof_ref`). `VERIFIED` is a protocol guarantee backed by a non-empty, deterministic `proof_ref`.
  </Accordion>
  <Accordion title="Exact Decimal & mpmath Solver Migration" icon="calculator">
    Full migration for `BondGuard`, `DerivativesGuard`, and `RiskGuard`. Option Greeks and yield calculations are exact, quantized strings rather than floating-point approximations.
  </Accordion>
  <Accordion title="Fail-Closed OpenResponses & AML Hardening" icon="lock">
    Fail-closed enforcement across `OpenResponsesIntegration` and unified AML high-risk country list validation.
  </Accordion>
</AccordionGroup>
